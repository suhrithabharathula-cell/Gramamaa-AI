# Gramamaa-AI
 This project is an AI-powered web voice assistant built using HTML, CSS, JavaScript, Node.js, and OpenAI API. It allows users to ask questions through voice or text in English and Telugu, receive intelligent AI-generated answers, and listen to responses using speech synthesis for a simple, interactive experience.
